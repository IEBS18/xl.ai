InsiPredict is an AI-powered modern spreadsheet designed to simplify and accelerate data work. It combines familiar spreadsheet features and formulas with advanced AI and supports Python, SQL, and JavaScript for powerful data analysis. Users can import files via drag-and-drop, supporting CSV, Excel, and Parquet formats, or connect directly to SQL databases.
Data can be exported easily by selecting and right-clicking to export as CSV. Files and .grid project files can be shared and downloaded for collaboration.
Code can be added in cells via AI suggestions or manually by invoking the code menu. Code cells are isolated: variables and imports don’t carry over between them, but their outputs can be referenced in the sheet.
InsiPredict supports structured data tables, which currently do not support formulas or code but will in the future. Cells and tables can be formatted using toolbar options or AI assistance. The AI chat interface accepts PDFs, images, and other files via attachment or drag-and-drop to enhance data interaction.
