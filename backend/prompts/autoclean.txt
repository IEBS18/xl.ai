```You will receive a pandas DataFrame in which:

- **Row 1** contains the column headers.  
- **Rows 2…n** contain the corresponding data values.

Your goal is to turn this into a two-column time-series table (`Date`/`Value`) for downstream preprocessing.

Your tasks:

1. **Header promotion & date detection/reshaping**  
   - Promote row 1 into `df.columns` and drop it.  
   - If one column parses cleanly as dates, rename it `Date` and gather all other columns as `Value`.  
   - Otherwise, treat the existing column names as dates and unpivot (melt) the table into two columns:  
     - `Date` (parsed from the former header names)  
     - `Value` (the corresponding cell values)

2. **Type conversion**  
   - Convert `Date` → `datetime64[ns]` and `Value` → numeric (coerce errors).  
   - Drop or impute missing values.  
   - Return a DataFrame with exactly two columns: `Date` (datetime) and `Value` (float).

3. Convert 'Date' to pandas datetime type and 'Value' to numeric, handling errors and missing values.

4. Handle missing values by imputing with central tendencies (mean or median) or interpolation as suitable.

5. Normalize and standardize the numeric columns using scikit-learn preprocessing tools.

6. Remove duplicates, sort by date, and ensure the time series has a regular frequency, filling missing dates as needed.

7. Return the cleaned and properly formatted data **as a JSON-serializable list of dictionaries**, ready to be converted back to a pandas DataFrame using:

import pandas as pd
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import MinMaxScaler

def json_to_dataframe(json_data):
    # Parse JSON with cell addresses into dict of rows
    rows = {}
    for cell, content in json_data.items():
        col = ''.join(filter(str.isalpha, cell))
        row = int(''.join(filter(str.isdigit, cell)))
        if row not in rows:
            rows[row] = {}
        rows[row][col] = content.get('value')
    df = pd.DataFrame.from_dict(rows, orient='index')
    df.columns = df.iloc[0]  # first row as header
    df = df.drop(index=df.index[0]).reset_index(drop=True)
    return df

def reshape_if_needed(df):
    date_cols = [col for col in df.columns if pd.to_datetime(col, errors='coerce') is not pd.NaT]
    if len(date_cols) > 0:
        # melt date columns to ds, y
        id_vars = [col for col in df.columns if col not in date_cols]
        df_melted = df.melt(id_vars=id_vars, var_name='ds', value_name='y')
        df_melted['ds'] = pd.to_datetime(df_melted['ds'], errors='coerce')
        df_melted['y'] = pd.to_numeric(df_melted['y'].str.replace(',', ''), errors='coerce')
        return df_melted.dropna(subset=['ds', 'y'])
    else:
        # assume ds and y columns already exist or infer them
        df['ds'] = pd.to_datetime(df['Date'], errors='coerce')
        df['y'] = pd.to_numeric(df['Sales'].str.replace(',', ''), errors='coerce')
        return df.dropna(subset=['ds', 'y'])

def clean_data(df):
    # Impute missing y with median
    imputer = SimpleImputer(strategy='median')
    df['y'] = imputer.fit_transform(df[['y']])
    # Normalize y
    scaler = MinMaxScaler()
    df['y_scaled'] = scaler.fit_transform(df[['y']])
    # Sort and index by date
    df = df.drop_duplicates(subset=['ds']).sort_values('ds').reset_index(drop=True)
    return df
