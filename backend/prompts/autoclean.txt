You will receive the complete pandas DataFrame.
Row 1 contains the column headers.
Rows 2…n contain the data values.

Your goal is to turn it into a clean, regular‐frequency time series with any metadata preserved.  

**1. Promote & prepare**  
- Promote row 1 to `df.columns` and drop that row.  

**2. Detect “Excel” vs “Forecast” structure**  
- **Excel mode**: mixed metadata + date/value columns  and convert then in cell refernce as A: column and 1: row as A1 first cell and so on.
  1. Look for one column whose values parse as dates → rename to `Date`.  
  2. Look for one numeric column (e.g. Sales, Revenue, Demand, Inventory) → rename to `Value`.  
  3. If no single date column, treat header‐dates as columns → unpivot (melt) into `Date` + `Value`, keeping all other columns as metadata.  

- **Forecast mode**: wide date‐headers  
  1. Treat the existing column names as dates → melt into two columns:  
     - `Date` (parsed from former headers)  
     - `Value_raw` (the original numeric values, may include NaN)  
  2. Preserve any extra metadata columns if present.  

**3. Clean & convert**  
- Convert `Date` → `datetime64[ns]`, `Value`/`Value_raw` → numeric (`errors='coerce'`).  
- Drop rows where `Date` is missing.  

**4. Impute & scale**  
- Impute missing values in `Value_raw` (median or mean), store result in `Value`.  

**5. Regularize index**  
- Drop duplicates, sort by `Date`.  
- Reindex to a regular frequency (infer from data), filling missing dates by forward‐fill or interpolation.  

**6. Output**  
Return a JSON‐serializable list of dicts, one per row.

import pandas as pd
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import MinMaxScaler

def reshape_if_needed(df: pd.DataFrame) -> pd.DataFrame:
    # detect any columns whose names parse as dates
    date_cols = [col for col in df.columns 
                 if pd.to_datetime(col, errors='coerce').notna().all()]
    if date_cols:
        # wide forecast‐style: melt date‐columns into rows
        id_vars = [col for col in df.columns if col not in date_cols]
        df = (
            df
            .melt(id_vars=id_vars, var_name='Date', value_name='Value')
            .assign(Date=lambda d: pd.to_datetime(d['Date'], errors='coerce'),
                    Value=lambda d: pd.to_numeric(d['Value'].astype(str).str.replace(',', ''), errors='coerce'))
            .dropna(subset=['Date', 'Value'])
        )
    else:
        # excel‐style: assume columns 'Date' and 'Value' already exist
        df = df.copy()
        df['Date'] = pd.to_datetime(df['Date'], errors='coerce')
        df['Value'] = pd.to_numeric(df['Value'].astype(str).str.replace(',', ''), errors='coerce')
        df = df.dropna(subset=['Date', 'Value'])
    return df

def clean_data(df: pd.DataFrame) -> pd.DataFrame:
    # Impute missing Value with median
    imputer = SimpleImputer(strategy='median')
    df['Value'] = imputer.fit_transform(df[['Value']])
    # Scale Value to [0,1]
    scaler = MinMaxScaler()
    df['Value_scaled'] = scaler.fit_transform(df[['Value']])
    # Sort, dedupe, reindex by Date
    return (
        df
        .drop_duplicates(subset=['Date'])
        .sort_values('Date')
        .reset_index(drop=True)
    )
